# Handoffs

Add a short Markdown note here only when work must continue in another task.
Include:

- branch and exact commit;
- objective and assurance lane;
- completed validation and artifact paths;
- unresolved finding or blocker;
- next exact command;
- files or worktrees that must not be overwritten.

Delete the note after the work merges or is abandoned. This directory is a
continuity aid, not a second backlog.
